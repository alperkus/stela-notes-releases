# Stela Notes — releases

Installers for **Stela Notes**, a free notes app for Windows and macOS by XSecure.

Download the latest version from the [Releases](https://github.com/alperkus/stela-notes-releases/releases) page:

- Windows: `.exe` installer
- macOS: `.dmg` (not yet signed by Apple: open it with right-click → Open the first time)

This repository holds release files only. The source code is not published here.
